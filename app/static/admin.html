제품 검토

승인된 제품만 검색과 AI 상담에 사용돼요. 근거 자료 URL이 없으면 승인할 수 없어요.

후기 관리

신고 3건이 쌓이면 자동으로 숨겨져요. 복구하면 신고 기록이 지워져요.

커뮤니티 관리

글·댓글은 신고 3건이 쌓이면 자동으로 숨겨져요.

RUTI Plus 지급 (테스터용)

결제 연동 전까지 테스터에게 Plus를 지급하거나 회수할 수 있어요.

식약처 성분 데이터

배포 서버에 성분 사전을 채워요. 먼저 '식약처에서 바로 받기'를 눌러 보고, 해외 서버라 막히면 PC에서 만든 파일을 올려 주세요.

파일 만들기 (PC, RUTI 폴더): python -m scripts.mfds export → ruti-ingredients.json.gz

제품 전성분 일괄 등록

여기 등록한 제품은 사용자가 앞면만 찍거나 제품명만 입력해도 바로 분석돼요. 쇼핑몰 자료를 자동으로 긁어오지 말고, 제품 뒷면이나 브랜드 공식 자료를 보고 옮겨 주세요.

AI 사용량 (최근 7일)

비용은 .env의 단가 기준 추정치예요. 캐시 적중은 AI를 부르지 않아 비용이 없어요.
