# 구글 플레이 '데이터 보안(Data safety)' 답안 초안

구글 플레이 콘솔 → 앱 콘텐츠 → 데이터 보안에 이 내용대로 답한다.
**개인정보 처리방침(/privacy)과 내용이 같아야 한다.** 기능이 바뀌면 둘 다 고친다.
(2026-11-08, 실제 코드 기준으로 작성. 출시 전 전문가 검토 필요)

## 기본 질문
| 질문 | 답 | 근거 |
|---|---|---|
| 앱이 사용자 데이터를 수집하거나 공유하나요? | 예 (수집) | 회원가입·피부 정보·상담 |
| 전송 중 데이터가 암호화되나요? | 예 | 모든 통신 HTTPS |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 예 | 앱 내 회원 탈퇴 + https://ruti.onrender.com/account-deletion |
| 독립 보안 검토를 받았나요? | 아니요 | |

## 수집하는 데이터 유형
"공유" = 제3자에게 넘김. 서비스 제공을 위한 처리 위탁(OpenAI, Render)은 구글 기준상 '공유'가 아니다 (서비스 제공자).

| 구글 분류 | RUTI에서 해당하는 것 | 수집 | 공유 | 필수/선택 | 목적 |
|---|---|---|---|---|---|
| 개인 정보 > 이름 | 이름, 닉네임 | 예 | 아니요 | 필수 | 앱 기능, 계정 관리 |
| 개인 정보 > 사용자 ID | 아이디 | 예 | 아니요 | 필수 | 계정 관리 |
| 건강 및 피트니스 > 건강 정보 | 피부 타입·민감 성분·피부 고민·임신 여부, 피부 컨디션 기록 | 예 | 아니요 | 선택 (민감정보 동의 시) | 앱 기능, 맞춤 설정 |
| 메시지 > 기타 인앱 메시지 | AI 상담 대화, 커뮤니티 글·댓글, 후기 | 예 | 아니요 | 선택 | 앱 기능 |
| 사진 및 동영상 > 사진 | 화장품 성분표 사진 | 예 (**일시적**, 분석 후 저장 안 함) | 아니요 | 선택 | 앱 기능 |
| 앱 활동 > 앱 상호작용 | 분석 기록, 내 화장대, 루틴 체크, 도움돼요·신고·차단 | 예 | 아니요 | 선택 | 앱 기능 |
| 앱 활동 > 기타 사용자 생성 콘텐츠 | 직접 적은 피부 정보, 제품 전성분 공유 | 예 | 아니요 | 선택 | 앱 기능 |
| 앱 정보 및 성능 > 비정상 종료·진단 | 서버 접속 기록(IP·시각) | 예 | 아니요 | 필수 | 보안, 오류 확인 |

수집하지 않음: 위치, 연락처, 결제 정보(스토어가 처리), 기기 ID, 광고 ID, 웹 검색 기록, 파일, 오디오, 캘린더.

## 사진에 대한 추가 설명 (심사 메모에 적기)
- 사진은 성분 글자를 읽으려고 OpenAI API로 보내고, 분석이 끝나면 서버에 저장하지 않는다.
- '일시적으로 처리'(ephemeral) 항목에 체크한다.

## 건강 앱 선언 (앱 콘텐츠 → 건강 앱)
- 의료 기기 아님. 화장품 성분 정보·스킨케어 안내 앱.
- 앱 설명과 화면에 "의료 진단을 대신하지 않아요" 문구 있음 (분석 결과, 상담, 루틴 추천, 피부 타입 테스트).
- 진료가 급할 수 있는 증상은 상담에서 진료 안내로 바꿔 답함.

## 사용자 제작 콘텐츠(UGC)
- 이용약관 동의 후 작성, 글마다 신고·차단 기능, 신고 3건이면 자동 숨김, 관리자 검토 화면 있음.
